# Katanalı Eşekler — Düello

Saf HTML5 Canvas + JavaScript ile çizilmiş, katanalı iki eşek samurayın dövüş animasyonu. Tek dosya (`index.html`), kütüphane yok: tarayıcıda aç, oynasın.

**Kontroller:** tıkla / `S` ses aç-kapat (sesler WebAudio ile sentezlenir) · `Boşluk` duraklat · `R` baştan · `←` `→` 1 sn geri/ileri sar · `index.html?t=12.5` ile belirli ana atla.

**Dövüş (~26 sn, döngü):** selam → yaklaşma → ilk çarpışma ve kilitlenme → tepeden savurma / kaçış / bant kesen karşı atak → havada üçlü çarpışma → fırıldak kesik, eğilip yukarı kesikle katanayı uçurma → gerilim → geçip giden kesik (zaman donması) → K.O. ve zafer.
